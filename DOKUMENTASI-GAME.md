## 2. 🎯 TUJUAN & LATAR BELAKANG

Game ini dirancang sebagai media edukasi interaktif dan alat pengumpulan data penelitian Karya Ilmiah Remaja (KIR). Pemain diajak merasakan langsung berbagai situasi perundungan yang kerap terjadi di lingkungan sekolah dan media sosial, memahami dampak emosionalnya, serta belajar mengambil keputusan yang sehat dan berani.

### Nilai-Nilai Edukasi Utama:
1. **Memahami Dampak Perundungan**: Menyadari bahwa kata-kata dan tindakan agresif menimbulkan luka psikologis mendalam.
2. **Keberanian Melapor**: Mengikis rasa takut dan stigma bahwa melapor ke guru/orang tua adalah tanda kelemahan.
3. **Mencegah Kekerasan Balasan**: Memahami bahwa membalas kekerasan dengan kekerasan justru memperburuk situasi.
4. **Mencari Ruang Aman**: Mengetahui peran penting Guru Bimbingan & Konseling (BK) sebagai pendamping terpercaya di sekolah.

## 3. 👥 TOKOH & KARAKTER

Permainan menyediakan 4 tokoh utama yang dapat dipilih pemain dengan ciri fisik dan latar belakang yang mencerminkan keragaman siswa di sekolah Indonesia:

### Karakter Pemain:
| Tokoh | Ciri Fisik & Latar Belakang | Fokus Konflik |
|---|---|---|
| **Nadira** | Siswi, tubuh gemuk, rambut ikal. | Perundungan verbal (*body shaming*) & rasa rendah diri. |
| **Alya** | Siswi, tubuh kurus, kulit pucat, berjerawat. | Ejekan fisik dan pengucilan oleh teman sebaya. |
| **Rafa** | Siswa, tubuh besar/gemuk, kulit sawo matang. | Diremehkan kemampuan fisiknya & dijadikan bahan olok-olok. |
| **Reyan** | Siswa, tubuh kurus, berjerawat, pendiam. | Diintimidasi di sekolah dan dijadikan sasaran ejekan. |

### Tokoh Pendukung & Pelaku:
- **Pelaku Siswa Laki-Laki (Bimo, Yudha, Rafi)**: Representasi pelaku perundungan di kelas, kantin, dan media sosial.
- **Pelaku Siswi Perempuan**: Karakter yang menyebarkan komentar pedas dan pengucilan sosial.
- **Bu Guru / Petugas Sekolah**: Figur otoritas pelindung di sekolah.
- **Teman Baik**: Sahabat pendukung (*upstander/bystander* positif).

## 4. 🎮 ALUR CERITA & STRUKTUR PERMAINAN

Permainan terdiri dari **12 Adegan Utama** yang terbagi dalam **3 Level Tematik** + **3 Pertarungan Boss Refleksi**:

```
[Mulai Game] ➔ [Pilih Karakter & Input Identitas] ➔ [Tutorial] 
  ➔ [Level 1: Perundungan Verbal (3 Adegan)] ➔ [Boss 1: Negative Thoughts] ➔ [Edukasi 1]
  ➔ [Level 2: Perundungan Fisik (3 Adegan)]  ➔ [Boss 2: Fear / Ketakutan]   ➔ [Edukasi 2]
  ➔ [Level 3: Cyberbullying (3 Adegan)]      ➔ [Boss Final: The Crack of Soul]
  ➔ [Layar Akhir: True Ending, Rapor Nilai, & Sinkronisasi Google Sheets]
```

### Rincian Level:

#### 🟢 LEVEL 1 — PERUNDUNGAN VERBAL
- **Adegan 1 (Ruang Kelas)**: Ejekan penampilan saat pergantian jam pelajaran.
- **Adegan 2 (Kantin Sekolah)**: Sindiran dan cemoohan saat membeli makanan.
- **Adegan 3 (Perpustakaan)**: Bisik-bisik dan ejekan saat belajar kelompok.
- **Boss 1 (Negative Thoughts)**: Melawan bisikan pikiran yang meremehkan harga diri sendiri.

#### 🟡 LEVEL 2 — PERUNDUNGAN FISIK
- **Adegan 1 (Taman Bermain)**: Sengaja didorong hingga terjatuh saat permainan.
- **Adegan 2 (Lapangan Bola)**: Dilempar bola secara sengaja oleh kelompok pelaku.
- **Adegan 3 (Jalan Pulang)**: Intimidasi fisik dan penendangan barang bawaan.
- **Boss 2 (Fear)**: Mengatasi rasa takut berlebih yang melumpuhkan keberanian untuk bersuara.

#### 🟣 LEVEL 3 — PERUNDUNGAN DIGITAL (CYBERBULLYING)
- **Adegan 1 (Media Sosial)**: Komentar kebencian pada unggahan foto pribadi.
- **Adegan 2 (Grup Chat & Notifikasi)**: Teror pesan beruntun dan serangan siber secara berkelompok.
- **Adegan 3 (Penyebaran Foto Viral)**: Foto yang diedit dan disebarkan tanpa izin.
- **Boss Final (The Crack of Soul)**: Mengintegrasikan seluruh keberanian untuk menyembuhkan luka batin dan mematahkan siklus trauma.

## 5. ⚖️ MEKANIKA PERMAINAN & SISTEM STATUS

### Tiga Status Utama (Karakter Status):
1. **🌸 Hope (Harapan)**: Keyakinan diri bahwa situasi dapat membaik dan ada masa depan yang lebih cerah.
2. **⭐ Courage (Keberanian)**: Keteguhan hati untuk bersuara, melapor, dan menolak diperlakukan semena-mena.
3. **❤️ Mental (Kesehatan Mental)**: Daya tahan psikologis dalam menghadapi stres dan tekanan.

- **Nilai Awal**: Ketiga status mulai pada angka **70 poin**.
- **Ambang Gagal (Game Over / Ulang Adegan)**: Jika salah satu status turun **di bawah 30 poin**, hari terasa terlalu berat dan pemain diberikan kesempatan mengulang adegan untuk mencoba pendekatan berbeda.

### Dampak 4 Pilihan Tindakan:
Di setiap akhir adegan, pemain dihadapkan pada 4 pilihan respon:

| Tindakan | Dampak Status | Makna Edukasi |
|---|:---:|---|
| **Melaporkan** *(Lapor Guru / Orang Tua)* | **+15** | Tindakan terbaik yang menyelesaikan akar masalah secara sistemik. |
| **Pergi / Cari Dukungan** *(Menjauh / Sahabat)* | **+5** | Menjauhkan diri dari bahaya fisik/mental langsung dan mencari teman suportif. |
| **Diam Saja** *(Memendam Masalah)* | **−5** | Menghindari keributan sesaat, tetapi memperpanjang beban batin. |
| **Membalas dengan Agresi** *(Marah / Menyerang)* | **−15** | Memperkeruh situasi, memicu keributan massal, dan menurunkan status drastis. |

## 6. 📊 SISTEM PENGUMPULAN DATA SISWA & GOOGLE SHEETS (OPSI A)

Game terintegrasi secara *real-time* dengan Google Spreadsheet milik guru pembimbing / peneliti KIR tanpa membebani siswa:

### A. Input Data di Awal:
Layar *Pilih Karakter* mewajibkan pengisian identitas dengan validasi otomatis:
- **Nama Karakter / Siswa**: Minimal 2 huruf (wajib).
- **Asal Sekolah**: Minimal 4 huruf (wajib, contoh: *SMP Negeri 1 Surabaya*).
- **Kelas**: Minimal 2 karakter (wajib, contoh: *IX-B / X MIPA 1*).

### B. Pengiriman Otomatis & Layar Akhir:
Saat tamat (*True Ending*), game otomatis mengirimkan ringkasan hasil ke **Google Apps Script**:
- **Data yang Tercatat di Spreadsheet**: Waktu selesai (WIB), Nama, Asal Sekolah, Kelas, Karakter, Skor Akhir (Hope, Courage, Mental, Pilihan Baik), Total Tindakan (Lapor, Pergi, Diam, Balas), Jumlah Restart, Durasi Main (menit), dan Status Akhir.
- **Proteksi Penguncian Tombol**: Tombol *Main Lagi*, *Menu Utama*, dan *Keluar* otomatis terkunci (*Disabled*) sampai muncul notifikasi `✅ Data Berhasil Terkirim ke Guru!`.
- **Mekanisme Offline-Safe**: Jika internet siswa terputus, data tersimpan di `localStorage` dan tombol `🔄 Kirim Ulang Data` siap digunakan saat internet kembali menyala.

## 7. 🤝 LAYANAN KONSELOR & BANTUAN SISWA (BK)

Sesuai standar etika penelitian dan psikologi pendidikan, game menyediakan informasi rujukan bantuan psikologis:

1. **Menu Bantuan (`modBantuan`)**: Informasi ruang Bimbingan & Konseling (BK) dan arahan menghubungi guru konselor sekolah.
2. **Layar Akhir Permainan (`sEnd`)**: Kartu khusus bertajuk *"🤝 BUTUH DUKUNGAN ATAU TEMAN CERITA?"* untuk siswa yang merasa tertekan atau mengalami perundungan nyata.
3. **Menu Jeda (`sPause`)**: Teks pengingat cepat akses layanan BK sekolah saat game sedang dijeda.

## 8. 🛠️ TEKNOLOGI & ARSITEKTUR KODE

```
crack-of-soul/
├── TheCrackOfSoul-v2.html     ← File bundle mandiri utama (Semua aset ter-embed)
├── dist/                      ← Direktori siap rilis untuk Vercel / PWA Hosting
│   ├── index.html             ← Versi Web dengan Service Worker PWA
│   └── sw.js, manifest.json   ← PWA Offline Support
├── src/
│   ├── game-shell.html        ← Kerangka HTML/CSS utama, UI & Game Engine
│   ├── chars.js               ← Engine Rigging Karakter 2-Lapisan (Kepala + Badan SVG)
│   ├── latar.js               ← Sistem Latar Pintar SVG & Deteksi Gambar Level
│   └── audio.js               ← Sintesis Efek Suara (21 FX) & Musik (7 BGM) via Web Audio API
├── google-apps-script.js      ← Kode backend Google Apps Script untuk Google Sheets
├── PANDUAN-GOOGLE-SHEETS.md   ← Panduan pemasangan spreadsheet 2-menit untuk guru
├── build-game.js              ← Script compiler (Base64 embedder)
└── uji-v2.js                  ← Script uji otomatis Playwright (End-to-End Test)
```

### Keunggulan Teknis:
- **0 KB File Audio Eksternal**: 21 efek suara dan 7 musik latar dihasilkan secara sintetis via JavaScript Web Audio API (*Chiptune/Synthesizer*), menghemat kuota dan mempercepat loading.
- **2-Layer Cutout Character Rig**: Tokoh dapat bernapas, mengedip, dan berbicara secara dinamis melalui manipulasi CSS transform pada SVG tanpa butuh library berat seperti Live2D atau Unity.
- **Level Scoping Background System**: Sistem pencegah kebocoran latar memastikan gambar ilustrasi hanya berganti sesuai level yang sedang dimainkan.

## 9. 🚀 PANDUAN BUILD & DEPLOYMENT

### Menjalankan Lokal / Menguji Game:
1. Buka file [`TheCrackOfSoul-v2.html`](./TheCrackOfSoul-v2.html) langsung di browser Google Chrome / Firefox.
2. Untuk menjalankan pengujian otomatis:
   ```bash
   node uji-v2.js
   ```

### Membangun Ulang Bundle (Setelah Edit Kode):
```bash
npm run build
```
*Perintah ini otomatis mengompilasi `src/` ke `TheCrackOfSoul-v2.html`, menyalin ke `dist/index.html`, dan menginjeksi Service Worker PWA.*

### Deploy ke Vercel:
```bash
git add .
git commit -m "feat: pembaruan sistem dan dokumentasi game"
git push origin main
```
*Vercel akan otomatis mendeteksi repository GitHub dan melakukan deployment instan.*
